## Лабораторна робота N1

# Файли

# 1. `lab1.ipynb` - основний код лабораторної роботи у вигляді IPython ноутбуку. Тут був попередній препроцесинг та візуалізація даних. Також в цьому файлі знаходиться код для навчання та оцінки моделей.
# 2. `requirements.txt` - файл з переліком необхідних бібліотек для запуску коду. Ви можете встановити їх за допомогою команди `pip install -r requirements.txt`.
# 3. `tensorflow_feature_extraction.ipynb` - скрипт для екстракції ознак з використанням TensorFlow. Цей файл містить код для завантаження попередньо навчених моделей та отримання ознак з зображень.
# 4. 'cards.zip' - Архів з необхідними даними - натреновані модельки, зображення карт, feature extraction файли

# Запуск роботи
# 1. Встановіть необхідні бібліотеки, виконавши команду `pip install -r requirements.txt` у терміналі
# 2. Відкрийте файл 'unzip.ipynb' та виконайте код для розпакування архіву `cards.zip`. Це створить папку `cards` з усіма необхідними даними для лабораторної роботи.
# 3. Відкрийте файл `lab1.ipynb`. Виконайте весь код
# 4. [OPTIONAL] Відкрийте файл `tensorflow_feature_extraction.ipynb` для повторної екстракції ознак
