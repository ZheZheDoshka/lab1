## Лабораторна робота N1

### Файли

- `lab1.ipynb` - основний код лабораторної роботи у вигляді IPython ноутбуку. Тут був попередній препроцесинг та візуалізація даних. Також в цьому файлі знаходиться код для навчання та оцінки моделей.
- `requirements.txt` - файл з переліком необхідних бібліотек для запуску коду. Ви можете встановити їх за допомогою команди `pip install -r requirements.txt`.
- `tensorflow_feature_extraction.ipynb` - скрипт для екстракції ознак з використанням TensorFlow. Цей файл містить код для завантаження попередньо навчених моделей та отримання ознак з зображень.
- `cards.zip` - Архів з необхідними даними - натреновані модельки, зображення карт, feature extraction файли
- `unzip.ipynb` - скрипт для розпакування архіву `cards.zip'.

### Запуск роботи
- Встановіть необхідні бібліотеки, виконавши команду `pip install -r requirements.txt` у терміналі
- Відкрийте файл 'unzip.ipynb' та виконайте код для розпакування архіву `cards.zip`. Це створить папку `cards` з усіма необхідними даними для лабораторної роботи.
- Відкрийте файл `lab1.ipynb`. Виконайте весь код
- [OPTIONAL] Відкрийте файл `tensorflow_feature_extraction.ipynb` для повторної екстракції ознак
