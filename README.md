## Лабораторні роботи

## Оскільки ряд дій актуальні для всіх лабораторних робіт, інструкції до всіх лабораторних робіт будуть в цьому файлі.

### Файли

- `lab1/lab1.ipynb` - основний код лабораторної роботи у вигляді IPython ноутбуку. Тут був попередній препроцесинг та візуалізація даних. Також в цьому файлі знаходиться код для навчання та оцінки моделей.
- `requirements.txt` - файл з переліком необхідних бібліотек для запуску коду. 
- `lab1/tensorflow_feature_extraction.ipynb` - скрипт для екстракції ознак з використанням TensorFlow. Цей файл містить код для завантаження попередньо навченої моделі (йшла разом з датасетом) та отримання ознак з зображень.
- `lab2/lab2.ipynb` - основний код лабораторної роботи n2 у вигляді IPython ноутбуку. Тут був попередній препроцесинг та візуалізація даних. Також в цьому файлі знаходиться код для оцінки моделей.
- `lab2/tf_classifier.ipynb` - ноутбук для тренування моделей для другой лабораторної роботи.
- `lab2/default.keras` - натренована без ваги модель для второй лабораторної роботи.
- `lab2/model_gamma_x.x**.keras` - натреновані з параметрами та focal loss моделі для второй лабораторної роботи. Параметри gamma та метод підбору alpha в назві файлу.
-  `lab3/lab3.ipynb` - основний код лабораторної роботи n3 у вигляді IPython ноутбуку. Тут був попередній препроцесинг та візуалізація даних. Також в цьому файлі знаходиться код для оцінки моделей.
- `lab3/tf_classifier_gan64.ipynb` - ноутбук для тренування моделей для третьої лабораторної роботи.
- `lab3/gan_training.ipynb` - ноутбук для тренування GAN моделі для третьої лабораторної роботи.
- `lab3/generate_images.ipynb` - ноутбук для генерації зображень за допомогою GAN моделі для третьої лабораторної роботи.
- `lab3/zip_unzip_generator_images.ipynb` - скрипт для розпакування архіву `generator_images.zip`, який містить згенеровані зображення для третьої лабораторної роботи.
- `lab3/{suit}_generator_xxx.pth` - збережений стан моделі генератора певного "suit" класу за xxx епоху. 
- `lab3/{suit}_discriminator_xxx.pth` - збережений стан моделі генератора певного "suit" класу за xxx епоху.
- `generator_images.zip` - архів з згенерованими зображеннями для третьої лабораторної роботи.
- `cards.zip` - Архів з необхідними даними - натреновані модельки, зображення карт, feature extraction файли
- `unzip.ipynb` - скрипт для розпакування архіву `cards.zip'.

### Підготовка до роботи
- Встановіть необхідні бібліотеки, виконавши команду `pip install -r requirements.txt` у терміналі
- Відкрийте файл 'unzip.ipynb' та виконайте код для розпакування архіву `cards.zip`. Це створить папку `cards` з усіма необхідними даними для лабораторної роботи.

### Запуск лабораторної роботи n1
- Відкрийте файл `lab1.ipynb`. Виконайте весь код. В даному файлі наявна візуалізація даних, навчання та оцінка заданих моделей.
- [OPTIONAL] Відкрийте файл `tensorflow_feature_extraction.ipynb` для повторної екстракції ознак

### Запуск лабораторної роботи n2
- Відкрийте файл `lab2.ipynb`. Виконайте весь код. В даному файлі наявна візуалізація даних та оцінка заданих моделей.
- [OPTIONAL] Відкрийте файл `tf_classifier.ipynb`, можна проглянути для отримання інформації про тренування моделей, реалізацію функцій втрат та підбір параметрів. Для повторного тренування моделей, можна виконати код в цьому файлі. Оскільки це лише приклад роботи метода, результат тренування моделі може сильно варюватися. При цьому підібрані параметри та F1 оцінка мають бути в середньому схожими.

### Запуск лабораторної роботи n3
- Відкрийте файл `zip_unzip_generator_images.ipynb` та виконайте код для розпакування архіву `generator_images.zip`
- Відкрийте файл `lab3.ipynb`. Виконайте весь код. В даному файлі наявна візуалізація даних та оцінка заданих моделей.
- [OPTIONAL] Відкрийте файл `tf_classifier_gan64.ipynb`, можна проглянути для отримання інформації про тренування моделей, реалізацію функцій втрат та підбір параметрів. Для повторного тренування моделей, можна виконати код в цьому файлі. Оскільки це лише приклад роботи метода, результат тренування моделі може сильно варюватися. При цьому підібрані параметри та F1 оцінка мають бути в середньому схожими.
- [OPTIONAL] Виконайте команду в терміналі  `pip install --pre torch torchvision --index-url https://download.pytorch.org/whl/nightly/cu126` для встановлення pytorch
- - [OPTIONAL] Відкрийте файл `gan_training.ipynb`, можна проглянути для отримання інформації про тренування GAN моделі, реалізацію функцій втрат та підбір параметрів. Для повторного тренування моделей, можна виконати код в цьому файлі. Потребує CUDA-сумісну відеокарту.
- - [OPTIONAL] Відкрийте файл `generate_images`, можна проглянути процес генерації та збереження згенерованих зображень. Можна повторити процес.
- Датасет та модель отримано з https://www.kaggle.com/datasets/gpiosenka/cards-image-datasetclassification/data
